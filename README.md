# OpenG2P Audit Manager

Centralised audit-event service for OpenG2P. Accepts CloudEvents over HTTP,
buffers through Kafka, persists to partitioned PostgreSQL.

All documentation — design, API, schema, scalability, deployment,
operational runbook, testing — lives at:

**→ https://docs.openg2p.org/platform/platform-services/audit-manager**

Please update only the GitBook documentation; this README is intentionally
a thin pointer and should not duplicate or diverge from the docs site.
